
# 🩺 Doctor Appointment Booking System
## Overview
The Doctor Appointment Booking System is a full-stack web application that enables patients to seamlessly book appointments with doctors online. Developed using the MERN Stack (MongoDB, Express.js, React.js, Node.js), the system offers a responsive and secure platform for both patients and doctors to manage their interactions efficiently. The application aims to eliminate the hassle of traditional appointment scheduling by offering real-time booking, role-based dashboards, and easy access to medical services.

## Features
User Authentication: Secure login/signup for patients, doctors, and admins using JWT.

Role-Based Dashboards: Separate dashboards for patients, doctors, and admin users.

Appointment Scheduling: Real-time booking with available date/time slots.

Doctor Management: Admin can approve/reject doctor registrations and manage users.

Appointment Tracking: View appointment history, booking status, and patient records.

Modern UI/UX: Clean, intuitive, and user-friendly interface.

## Technologies Used
Frontend: React.js, Tailwind CSS

Backend: Node.js, Express.js

Database: MongoDB (Mongoose ODM)

Authentication: JWT (JSON Web Tokens)

Other Tools: Redux, Axios, React Router, Moment.js
