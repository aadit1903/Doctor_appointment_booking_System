# 🩺 Doctor Appointment Booking System

## Overview  
The **Doctor Appointment Booking System** is a full-stack web application built with the **MERN Stack** (MongoDB, Express.js, React.js, Node.js), designed to facilitate seamless appointment scheduling between patients and healthcare professionals. The platform offers real-time booking capabilities, secure login via OTP verification, and a role-based interface for patients, doctors, and administrators.

## 🔐 New Feature: OTP-Based Secure Login  
Users can now log in using a secure **OTP (One-Time Password)** sent to their registered email after entering their password. This adds an extra layer of authentication and ensures that only authorized users access the platform.

## ✨ Features  
- **User Registration & Login**  
  - Secure login with password + OTP verification via email  
  - JWT-based session authentication  
- **Role-Based Dashboards**  
  - Separate dashboards for Admin, Doctor, and Patient  
- **Doctor Management**  
  - Admin can approve/reject doctor registration requests  
- **Appointment Booking**  
  - Real-time availability and booking by patients  
  - Doctors can view and manage scheduled appointments  
- **Responsive Design**  
  - Mobile-friendly, fully responsive UI built with Tailwind CSS  
- **Admin Panel**  
  - User and doctor management features for the system administrator

## 🛠️ Technologies Used  
- **Frontend**: React.js, Tailwind CSS, Vite  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Authentication**: JWT, Nodemailer (for OTP email service)  
- **Tools & Libraries**: Axios, React Router, Redux (if used)
